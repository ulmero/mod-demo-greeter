# mod-hello-world

A demo module for Ulmero, in module format 1. Adds a new tab called "Hello world" with some simple test UI. Good test for ensuring you can install external modules into your copy of Ulmero.

This module is published by the workflow in `.github/workflows/publish.yml`, which calls the publish workflow of `ulmero/platform`. See `docs/MODULES.md` in that repository.
